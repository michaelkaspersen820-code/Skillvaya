Official Android & Windows downloads
Can I install it on Android?

Open this site in Chrome on your Android phone and tap Download / install. If your browser offers installation, accept it. If it does not, open the live app and use the browser menu to choose “Install app” or “Add to Home screen”.

Can I install it on a Windows PC?

Open this site in a supported browser such as Microsoft Edge or Chrome and select Download / install. If the browser offers an app-install prompt, confirm it. Otherwise use the browser’s app/install menu.

Does the button download an APK or Windows .exe?

The website detects Android and Windows and sends each device to the matching installer download. The Android package runs a local app service and database on that phone; the Windows edition runs a local service on that PC. A shared online marketplace and live PayFast payments still require production hosting and the approved merchant callback.

Are payments available immediately?

Provider plans are shown in the app, but live PayFast checkout must be connected to the approved merchant account and public HTTPS deployment before real payments can be accepted reliably.
